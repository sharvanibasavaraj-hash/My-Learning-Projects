Learning Applications

This repository contains the applications I built while learning and practising web development technologies.

It focuses on applying concepts I learned in HTML, CSS, JavaScript and backend development by creating working applications and experimenting with different technologies.

Technologies Covered

1. HTML

- Created web pages using HTML.
- Practised forms, tables, lists and other HTML elements.
- Built page structures using semantic elements.
- Applied HTML concepts in practical applications.

2. CSS

- Practised styling and designing web pages.
- Worked with selectors, classes and IDs.
- Used Flexbox, positioning, margins, padding and layouts.
- Applied colours, fonts, borders and other styling properties.

3. JavaScript

- Applied JavaScript fundamentals in web pages.
- Worked with variables, functions, arrays and objects.
- Practised DOM manipulation and event handling.
- Implemented form validation.
- Used JavaScript to make web pages interactive.
- Practised asynchronous JavaScript using Promises, async/await and fetch.

4. React.js

- Created user interfaces using React.js.
- Practised JSX and reusable components.
- Worked with props and component state.
- Used React Hooks such as useState and useEffect.
- Implemented event handling and conditional rendering.
- Practised rendering lists using map() and keys.
- Built forms and handled user input.
- Worked with API integration and Local Storage.

5. Node.js

- Created backend applications using Node.js.
- Practised modules and importing packages.
- Worked with file handling and server-side JavaScript.
- Built applications using Node.js fundamentals.

6. Express.js

- Created servers using Express.js.
- Worked with routes and HTTP methods.
- Practised handling requests and responses.
- Built REST API applications.

7. Node.js + MySQL

- Connected Node.js applications to MySQL databases.
- Practised database operations using SQL.
- Implemented INSERT, SELECT, UPDATE and DELETE.
- Built backend applications that interact with a database.

8. Backend Development

- Created backend-only applications.
- Implemented CRUD operations.
- Built and tested REST APIs using Postman.
- Connected APIs to MySQL databases.
- Practised handling API requests and responses.

Purpose

The purpose of this repository is to maintain a collection of practical applications developed during my learning journey.

Each application represents the concepts I have learned and applied using different web development technologies.

Future Scope

I will continue adding applications as I learn more technologies and advance my development skills.

Separate mini projects and larger independent projects will be maintained in separate repositories.
